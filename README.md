# Portfolio

This repository contains a Next.js + Tailwind portfolio for Daiki Suzuki (daiki-moonlight). The site is scaffolded to be deployment-ready and includes example projects and an integrated To‑Do demo.

Quick start

1. Install dependencies
   - npm install
2. Run dev server
   - npm run dev
3. Build
   - npm run build

Notes
- Resume PDF: public/Taiki_Suzuki_Resume.pdf
- To‑Do demo available at /todo (client-side, persisted with localStorage)
- Contact API is a stub at /api/contact — you should wire up an email provider or serverless function

Deployment
- Deploy to Vercel by importing the GitHub repository (https://github.com/daiki-moonlight/portfolio)
